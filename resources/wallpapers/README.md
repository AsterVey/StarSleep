# Mist 背景素材

由内置 imagegen 于 2026-09-22 为星眠制作，面向 DeepSeek Harness 的 Dream Skin / Mist 浅色界面。不是从社区作者处下载的图片；社区插件与原创背景的来源分开标注。

| 文件 | 名称 | 实际尺寸 |
| --- | --- | --- |
| tidal-glass.png | 潮汐琉璃 | 1672×941 |
| cloud-fjord.png | 云湾 | 1672×941 |

使用内置 imagegen 生成，没有调用 CLI / API 备用路径。完整生成提示词分别见同目录 `tidal-glass.prompt.txt` 和 `cloud-fjord.prompt.txt`，也嵌入 PNG 元数据。PNG 原图随应用离线提供，星眠不会自动联网生成图片。

DeepSeek 导入入口：账号菜单 → 设置 → Theme / 外观 → 选择图片。配色选 Mist（干净明亮），建议透明度 80%，模糊 1–3 px。

## 同机性能观察

分别运行 v1.1.0 打包应用和 v1.2.0 构建结果；每种数据量连续观察可见和隐藏状态各 3.2 秒。统计窗口 IPC 的完整状态推送、时钟事件和本地存储 fsync 调用；同时读取 Electron 各进程指标。测试计划设在未来，采样期间没有实际任务到期。

| 计划数 | 完整状态推送，旧 → 新 | CPU 合计，旧 → 新 | 工作集合计，旧 → 新 |
| --- | --- | --- | --- |
| 0 | 3 → 0 | 4.22% → 3.04% | 461 → 459 MiB |
| 1 | 3 → 0 | 5.56% → 3.69% | 474 → 477 MiB |
| 50 | 3 → 0 | 7.47% → 4.32% | 501 → 516 MiB |
| 500 | 3 → 0 | 7.61% → 4.29% | 613 → 533 MiB |

新版以 3 次独立时钟事件代替可见窗口的完整状态推送。所有采样中，两版均未发生计划数据 fsync；隐藏后均为 0 次完整状态推送，新版也停止时钟事件，装饰动画处于停止状态。500 条计划的搜索操作约 194 ms，包含自动化通信与渲染等待开销。

这些是短时观测，不是耗电测量或性能保证；未测量电费、Token 节省量或长时间稳定功耗。工作集为 Electron 多进程指标之和，可能包含共享页面；个别数据量的内存并未下降。性能采样后仅做了圆盘尺寸和紧凑布局调整，调度及状态同步实现未改变。

## 数据兼容与测试边界

- 两版打包程序共用专用测试目录，比较计划标识、启用状态、准确截止时间、下一次执行、暂停状态、handled 及 overrides；升级后全部保留。新增设置缺省为提前 5 分钟和响铃 60 秒，新版偏好可保存并在重启后恢复。再用旧版读取，计划、暂停及延后保持一致。
- 所有测试使用 `--safe-mode` 和独立的 `STARSLEEP_QA_DATA`。没有读取或覆盖用户真实计划，也未升级或卸载用户正在使用的安装。
- 安装程序已构建；本轮使用其同源 `win-unpacked` 程序验证打包启动和兼容。**本轮没有重新执行安装、桌面快捷方式创建和卸载流程**，历史安装验证见根目录 `VALIDATION.md`。
- 文件测试替换原生选择器的返回值，再通过真实 IPC 读取和写入隔离文件；托盘测试调用真实菜单回调。没有模拟点击 Windows 文件选择器或托盘弹出菜单。
- 睡眠、系统时间和时区跳变使用模拟时钟及调度重建验证，没有让本机真正睡眠或调整系统时间。
- 音频验证播放与停止生命周期，没有替用户判断扬声器听感或静音状态。
- **没有实际关闭当前电脑。** 正式执行仍使用固定的 `shutdown.exe /s /f /t 0`。只有星眠运行时计划才有效，托盘完全退出立即停止；不注册 Windows 定时任务、服务、自动启动或唤醒任务。

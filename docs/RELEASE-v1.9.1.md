# 星枢 StarNexus v1.9.1 · 星门跃迁

第一作者：AsterVey。本轮为本地体验版，未发布 GitHub。

开场重新制作成约 6.4 秒的连续镜头：星门蓄能、加速穿越、抵达星枢。八重金属星门、冷蓝发光边缘、纵深星尘与光轨共同构成航道；镜头推进时带有轻微倾斜和视野变化，抵达后展开标题，再进入工作台。

- 开场期间让出中央空间，保留暂停、设置和窗口控制。
- 随时点击“进入工作台”或按 Esc 跳过；“星际观景”中可以重播。
- 关闭自动启动动画后仍可手动重播；静态档位与减少动态效果直接进入工作台。
- 提醒优先显示；隐藏或最小化后停止装饰绘制。
- 继续复用单个 Canvas 和窗口，开场结束、跳过或被提醒打断后释放专属几何体与材质。

## 本地使用

**先体验：双击 `体验星枢.cmd`。** 使用独立数据和安全关机替代器，不覆盖当前安装。

**安装：双击 `StarNexus-Setup-1.9.1.exe`。** 普通启动具备真实关机能力；软件运行时计划有效，关闭窗口进入托盘，完全退出停止执行。

`StarNexus-Source-1.9.1.zip` 用于开发，不是安装包。`星枢-v1.9.1-星门跃迁.webm` 为实际程序录屏，截图位于 `screenshots`。

计划格式、数据目录、Agent 接口和既有功能保持兼容。旧版本产物保留，本轮未操作真实客户端配置。许可仍禁止售卖软件及改版，第三方许可证沿用原记录。

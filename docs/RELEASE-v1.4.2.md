# 星眠 v1.4.2 · DeepSeek 背景库

第一作者：AsterVey。继续沿用项目禁止售卖许可。本版本仅本地体验，未发布 GitHub。

## 使用

下载 / 运行 **StarSleep-Setup-1.4.2.exe 安装**。想保留当前安装与数据，请使用交付目录中的「体验新版.cmd」：它启动独立数据目录及安全关机替代器，不会真正关机。源码 ZIP 用于开发，不是安装包。

打开「Agent 与美化 → DeepSeek 背景」，先预览，再导出。DeepSeek 需要社区 [dsh-dream-skin](https://github.com/RevolutionLA/dsh-dream-skin) 插件，在「账号菜单 → 设置 → Theme / 外观」选择「干净明亮」和「选择图片」。推荐壁纸透明度 80%、模糊 1–3 px；以实际文字可读性为准。原生导出对话框取消时不会显示成功。

## 背景与数据

- 潮汐琉璃：冰蓝玻璃、柔和折光、大面积留白。
- 云湾：清晨雾气、远山与平静水面。
- 两张图片均由内置 imagegen 生成，实际尺寸 1672×941，PNG。完整提示词在 `resources/wallpapers/*.prompt.txt`，同时嵌入源图元数据。本功能为离线素材库，不含在线图片生成服务。
- PNG / JPEG / WebP 自定义图片限制 10 MB；最小 320×180，单边最大 8192，总像素最大 3200 万，最多 24 张个人图片。个人导入会解码并保存 JPEG 副本，原文件不变；不支持 SVG 或动图。
- 个人背景与版本 1 索引保存在用户数据目录的 wallpapers 子目录。保留上一份索引备份。删除库中图片不会移除已经导出的副本或改变 DeepSeek 当前背景。
- 图片库独立于计划存储，不改变已有的版本 2 计划格式。

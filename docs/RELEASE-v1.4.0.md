# v1.4.0 开发预览：Agent 联动与原客户端美化

本地开发预览，尚未发布 GitHub，也未覆盖历史版本。第一作者 AsterVey，沿用禁止售卖许可。

## 本轮方向

美化对象是 **Codex、Claude、DeepSeek Harness 原有界面**。星眠提供主题导入、目标识别和配置入口，主题库配色展示不等于目标软件已经应用。

- Codex 原生主题：识别分享代码、备份外观字段、写入实际配置、选择性还原。保留模型和其他设置；外部修改发生后拒绝覆盖。
- Claude：识别商店版与独立安装版，检查 Theme Mod 加载器。兼容加载器存在时配置与还原主题 JSON，缺失时给出配置指南。
- Dream Skin ZIP 与 DSH 配色：格式识别、收纳、复制或导出，交给对应社区引擎导入。尚无统一的一键安装引擎能力。
- Agent 夜间联动：本机 hooks／DSH 连接器、任务选择、明确开启、完成报告、观察期、关机提醒、取消与延后。重启不重新开启；暂停、失败、失联、睡眠及时间跳变解除监控。

## 当前适配边界

- Codex 和 Claude 接入都需要客户端正确加载 hooks。Claude 仅针对桌面 Code 标签的本地会话，Chat / Cowork 未接入。
- 完成条件包含 Agent 自己明确报告完成，不是对所有工作结果的独立证明。普通停止输出、等待输入和进程退出不算完成。
- 本机 Codex 26.915.4065.0 的原生配置接口已核实，已在真实配置的隔离副本上验证写入和还原。尚未修改本机主题或验证其实际视觉效果。
- 本机 Claude 1.52386.6.0 是商店版，尚不能通过此次适配直接美化。星眠不自动修改其程序文件或完整性设置。
- DSH 连接器按当前公开接口实现，尚未通过完整真实模型任务的验收。
- 没有执行真实关机；完整安装／升级／卸载流程没有在当前用户安装上重做。

## 本地体验

优先运行交付目录的 `体验新版.cmd`：使用隔离数据，不关机、不修改真实客户端配置。

`StarSleep-Setup-1.4.0.exe` 是安装程序；主动安装会升级现有星眠，请在确认体验后使用。`StarSleep-Source-1.4.0.zip` 仅为开发源码，不能双击安装。

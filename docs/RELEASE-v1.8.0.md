# 星眠 v1.8.0 · 星际工坊

本地体验版，第一作者 **AsterVey**。本轮未发布 GitHub，历史安装包与标签保持不变。

## 先体验，再安装

- 推荐先双击 `release/v1.8.0/体验新版.cmd`。它打开同目录的程序，使用独立 `preview-data`，不会关机，也不会自动替换当前安装或客户端配置。
- 正式安装请双击 **StarSleep-Setup-1.8.0.exe**，无需安装 Node.js。主动安装新版可能升级已有安装。
- **StarSleep-Source-1.8.0.zip 是开发源码，不是安装包的压缩版。**

## 四个空间节点

主控台管理关机与闹钟；Agent 工作台集中用量、Skills 和夜间联动；美化工坊浏览社区主题并配置原客户端；系统维护提供只读体检、脱敏导出、日志与设置。

沉浸式界面使用一个 Three.js WebGL Canvas。点击导航时镜头推进，空白场景区域滚轮缩放；按钮支持键盘操作。拖动面板右下角，或选择紧凑、标准、展开调整尺寸。镜头与各区域尺寸会保留，搜索与筛选在切换节点后保留。

默认自适应动效。15 秒无操作降低目标帧率，持续掉帧依次减少粒子、分辨率和辉光，最终静态显示。可点击“重新启用动效”重试。设置 → 外观提供经典界面、低负载和静态模式。系统减少动态效果也会被遵循。隐藏、最小化、迷你模式时停止装饰绘制，真实提醒优先。

## 社区美化工坊

精选目录内置 8 个资源入口，其中 5 个固定提交的数据主题可以直接下载：Codex 的 Claude Warm 浅/深色，Claude 的 Arizona Iced Tea / Moonside，以及 DeepSeek 作者的 Aurora Test 示例包。其余资源跳转作者社区，准备对应加载器。

流程：**社区精选 → 下载到主题库 → 我的主题 → 查看目标与更改 → 备份并配置 → 在客户端核对 → 我已在客户端确认效果**。

下载可取消、重试，使用固定来源与 SHA-256 校验后才加入主题库。用户无须手动处理校验清单。卡片预览是配色示意，不是原客户端实测截图。可按客户端、明暗、格式、可配置状态筛选，或收藏常用资源；目录资料离线可读，下载需要联网。

支持拖入单个本地 JSON、TXT、`.codex-theme-v1`、CSS、Dream Skin ZIP，以及 PNG/JPEG/WebP 背景。图片进入 DeepSeek 背景库。CSS 和 ZIP 仅收藏、导出和展示加载器说明，不在星眠执行。导入不会自动应用。

- Codex：需要可识别的原生主题配置支持。
- Claude Desktop：需要兼容的 Theme Mod 加载器；星眠不会修改程序完整性设置或自动安装加载器。
- DeepSeek Harness：需要已启用的 Dream Skin 9.x，选择实际 DSH_HOME；退出 DeepSeek 后写入，重新启动后确认。

## 配置体检与安装恢复

体检检查客户端、加载器、目标目录、主题格式、备份记录及星眠管理的 Skills 文件。导出报告不包含本机配置路径、对话或凭据。体检的“就绪”仅说明文件和适配条件满足；美化效果需要在原客户端确认。

Skills 安装、移除和恢复新增独立 `skill-operation.json`。中断后重启会核对文件标识并完成尚未结束的移动与记录；遇到修改、缺失或目录冲突会保留文件、显示待处理状态，不覆盖用户内容。旧安装记录继续读取，计划存储不变。

`experience.json` 仍为版本 1，新增偏好在旧文件中使用默认值；计划存储仍为版本 2。工坊收藏、来源、效果确认与下载历史独立保存在版本 1 的 `workshop.json`。工坊或体验存储故障不停止有效计划。

## 运行规则

只有星眠运行时计划有效。关闭窗口进入托盘，完全退出后停止所有自动关机。没有 Windows 系统计划任务、开机自启或后台服务，不唤醒电脑、不补执行错过的关机。夜间联动仍需手动选择任务并开启，切页和重新启动不会自动开启。

测试证据见 [验收报告](VALIDATION-v1.8.0.md)，复用与完整许可见 [开源清单](OPEN-SOURCE-v1.8.0.md)。实际关机与真实客户端视觉效果未作为本轮自动化测试执行。

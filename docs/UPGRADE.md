# 升级与降级

## 从 v1.0.0 升级到 v1.1.0

1. 从托盘退出星眠，安装 v1.1.0。
2. 新版首次启动会读取原有计划，保留计划内容、启用状态和已有执行记录。
3. 数据保存在原来的 `%APPDATA%\StarSleep` 目录，升级前的原始数据额外保存为 `schedules.v1.backup.json`，后续保存不会覆盖此备份。

升级失败时不会覆盖原来的计划。若提示无法备份，请检查目录权限和磁盘空间；不要删除尚未核对的备份文件。

暂停全部计划后，即使退出并重新打开新版，仍保持暂停。主动恢复后仅执行未来触发点。

## 回到 v1.0.0

v1.0.0 不支持新版的数据格式。降级只能恢复升级之前的计划，新版期间的新增、修改与暂停状态不会自动并入旧版。

1. 在新版中导出计划，并另行复制整个 `%APPDATA%\StarSleep` 文件夹留存。
2. 从托盘完全退出新版。
3. 将 `schedules.v1.backup.json` **复制**为 `schedules.json` 和 `schedules.json.bak`，保留原升级备份文件。
4. 安装并打开 v1.0.0，重新核对计划的时间和启用状态。

如果找不到有效的升级前备份，请保留当前目录并使用新版，不要尝试把 JSON 中的版本号直接改小。

## 在另一台电脑上使用计划

在 v1.1.0 的「设置与关于」中选择「导出计划」，再在另一台电脑导入。
导入只追加计划定义，跳过重复和过期单次计划；所有导入项默认停用。
临时延后、执行记录、暂停状态和音量设置不随导出文件迁移。
普通计划使用电脑本地时间，跨时区导入后应重新核对。快捷任务保留原本的绝对执行时刻，并按当前电脑的时区显示日期和时间。

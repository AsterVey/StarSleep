# 星眠 v1.2.0 · 让今晚更好安排

**本地体验版，暂未发布到 GitHub。** 第一作者：[AsterVey](https://github.com/AsterVey)。

这一版保留冷蓝科幻风，重新安排界面空间：倒计时更紧凑，计划管理更宽敞，常用操作更容易找到。

## 新增与改进

- 搜索计划、组合筛选、按执行时间／创建时间／名称排序。
- 批量启停与删除、复制、跳过下一次、清理已结束的单次计划。
- 四个常用模板，填写后确认创建；副本默认停用。
- 编辑器显示时间预览、字段错误和未保存提示，支持 Ctrl+N／Ctrl+F／Esc。
- 声音与提醒、外观、数据管理、关于四个设置分区。
- 可选提前提醒和响铃时长，正在进行的提醒保持原截止时间。
- 执行记录筛选与文本导出，导入预览展示跳过原因。
- 减少完整状态推送和音量写盘，窗口隐藏后闹钟仍按时停止。

## 使用

安装使用 `StarSleep-Setup-1.2.0.exe`。`StarSleep-Source-1.2.0.zip` 是开发源码，不用于安装。
本地目录的 `体验新版.cmd` 打开隔离安全体验，不读取已有计划、不执行真实关机。

计划仅在软件运行时有效；关闭窗口进入托盘，完全退出停止计时。正式关机计划到点会强制关机，未保存内容可能丢失。

v1.1.0 数据无需格式升级，计划、暂停和临时延后会保留。旧版仍可读取计划，新提醒偏好在旧版中按旧版行为处理。

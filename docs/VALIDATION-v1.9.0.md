## 新界面与功能检查

- 启动显示新名称，提供立即跳过，单 WebGL Canvas；关闭启动动画后重启保持关闭。
- 观景收起面板，Esc 返回保留搜索；关机提醒立即结束观景并冻结装饰绘制。
- 主题创作生成 Codex 原生主题、Claude JSON、DSH JSON；保存不会应用到客户端。
- Codex 图片 ZIP 只含 `theme.json`、`theme.css`、`background.jpg`。使用背景库选择的真实图片生成，导出后重新导入能识别重复；非法 IPC 参数被拒绝。
- 900×650 起，100% / 125% / 150% / 200% 缩放检查；键盘焦点、Ctrl+N、Esc、导航和设置可达。高缩放需在内容区域滚动。
- 隐藏和迷你模式下，在稳定后的观测窗口内绘制计数增加为 0；只有一个 Electron BrowserWindow。
- 完成一轮集中视觉检查，修复小窗口预览宽度溢出、过高的重复标题和启动按钮的入场可见性，再完成一次确认。
- 作者介绍不再包含「借助 AI」，第一作者为 AsterVey。应用 ID、真实数据目录与连接协议保持兼容。

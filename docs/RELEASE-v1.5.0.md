## 下载与运行

**运行 StarSleep-Setup-1.5.0.exe 安装。** 只体验且保留现有安装、真实计划与客户端配置，请用同目录的「体验新版.cmd」。体验入口启动独立 preview-data，并拦截实际关机。**StarSleep-Source-1.5.0.zip 是开发源码，不是安装包。**

## 临时暂停

- 点击主界面底部「临时暂停」，选择 15 / 30 / 60 / 120 分钟，或未来 24 小时内的日期与时间。确认时开始暂停，当前提醒关闭、响铃停止，各条计划的启用状态保留。
- 托盘的临时暂停子菜单提供相同时长及「一直暂停」。主界面底部、迷你界面及托盘显示保存的恢复时间。主界面「恢复计划」可提前恢复；「一直暂停」取消自动恢复时间。
- 到期时跳过所有已经到点的执行，包括正好落在恢复时刻的任务；只重新安排严格晚于当前时间的计划，不补关机。
- 退出软件后没有后台计时。重新打开会读取原截止时间；尚未到期则继续暂停，已到期则跳过错过任务后恢复未来计划。休眠和系统时间变化沿用原有重新计算规则。
- 暂停立即解除 Agent 夜间联动，自动恢复不会重新开启联动。存储故障不会被自动恢复解除；从损坏主数据的备份恢复时，自动恢复时间被清除，所有计划保持停用与手动暂停。

## 备注与搜索

- 新建、编辑计划以及快捷计时均可写最多 500 字备注，支持换行。
- 列表显示两行摘要，悬停可查看完整文字；搜索匹配名称和备注。完整备注也显示在编辑器及到点提醒中。
- 复制计划、个人普通 / 快捷模板保留备注。模板仅预填，仍需确认才创建计划。
- 导出计划 JSON 包含备注，导入仍默认停用；去重比较也包含备注。备注不会自动发送给 Agent，执行记录不会附加备注全文。

## 数据与降级

计划文件继续使用版本 2，增加可选 pauseUntil 和 notes；模板仍为原有版本 1。旧数据缺少这些字段时不改变行为。

降级前应取消临时恢复时间（选择「一直暂停」或手动恢复），再备份数据。旧版不能管理临时恢复，也可能在编辑、导出计划或模板时丢失备注。本地体验使用独立目录，不会让旧安装读取新数据。

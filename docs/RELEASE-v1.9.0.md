# 星枢 StarNexus v1.9.0

星眠现更名为「星枢 StarNexus」：一个汇聚 Agent 工作、社区工具和个性化配置的 Windows 工作台。第一作者 AsterVey，沿用现有禁止售卖许可。本版本为本地体验版，未发布 GitHub。

## 体验新版

- 直接体验：运行交付目录中的 `体验星枢.cmd`。使用独立数据、安全关机替代器，不覆盖当前安装；主题配置也使用隔离客户端目录。
- 安装：运行 `StarNexus-Setup-1.9.0.exe`。安装后的普通启动仍有真实关机能力，请先保存工作再启用计划。
- `StarNexus-Source-1.9.0.zip` 是完整开发源码，不是安装程序。

## 启动与布局

启动展示约 3.8 秒的三维星际航行，点「进入工作台」或按 Esc 可立即跳过。设置 → 外观可关闭启动动画；减少动态效果、经典模式和正在提醒时均不播放。

点击「星际观景」可收起功能面板，滚轮调整镜头，按 Esc 或「返回工作台」恢复。导航、暂停、设置和窗口按钮仍可使用。提醒立即结束观景；隐藏或迷你模式停止装饰绘制。只使用一个 Three.js 场景，不新增窗口。

工作布局保留场景留白，缩小仪表与重复标题，工坊采用更大的双列主题封面。配色艺术封面和背景示意有明确标注，不冒充原客户端截图。

## 自制美化包

进入 **美化工坊 → 主题创作**，从雾海、深空、暖纸、鸢尾开始，调整背景、侧栏、正文、强调、辅助文字和分隔线。实时预览仅用于设计；客户端最终布局由对应加载器决定。

| 创作目标 | 产物 | 使用方式 |
| --- | --- | --- |
| Codex 原生配色 | `.codex-theme-v1` | 我的主题 → 检测并配置，或通过 Codex 原生外观导入 |
| Codex 图片主题 | `.zip` | Dream Skin 托盘 → 导入主题 ZIP → 切换主题 |
| Claude | Theme Mod JSON | 已有兼容 Theme Mod 加载器后，在我的主题配置 |
| DeepSeek | Dream Skin v1 主题 JSON | 已有 Dream Skin 9.x 后，在我的主题配置；图片通过背景库单独配置 |

Codex 图片主题可使用自己的 PNG、JPEG、WebP 图片（最大 10 MB），或选用内置背景，支持横向焦点。生成包包含 `theme.json`、`theme.css` 和经过本地解码的 `background.jpg`。不包含安装器、任意脚本或远程资源；保存包不会改动客户端。导出后可再次拖回星枢，重复包会被识别。

正文与背景的配色对比度低于 4.5:1 时，编辑器提示调整后再保存。这是纯色对比检查，图片内容仍需用户在客户端检查可读性。图片使用与再分发应拥有相应权限。

原生 Codex 文档确认支持配色、字体及透明侧栏；图片背景使用社区 Dream Skin，并非原生主题字段。加载器与客户端版本需要匹配，星枢不会自动修改 Codex 或 Claude 二进制文件。

## 改名与兼容

界面、窗口、托盘、安装程序与新建快捷方式使用「星枢」。作者介绍改为工具、自动化与交互设计，第一作者仍为 **[AsterVey](https://github.com/AsterVey)**。

原有应用标识、`%APPDATA%\StarSleep` 数据目录、连接协议和备份文件名保持兼容；旧计划、暂停状态、主题和接入配置继续读取。改名不会建立另一套真实计划数据。源码目录与 [GitHub 仓库地址](https://github.com/AsterVey/StarSleep) 保持原址，历史发布和本地产物不变。

计划仍只有软件运行时有效。关闭窗口隐藏到托盘，完全退出停止执行；不注册 Windows 任务计划、不自动启动、不唤醒电脑、不补执行错过的关机。

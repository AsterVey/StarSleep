# 星眠 v1.0.0 · 给夜间 Agent 工作设一个终点

睡前把工作交给 Agent，也给电脑安排一个休息时间。

星眠是一款中文 Windows 定时关机与闹钟软件。你决定截止时间，它负责在
关机前提醒，并在到点后请求 Windows 关机。冷蓝控制台、环形倒计时、
指尖波纹与电子音反馈，让一个小工具也用得舒服。

## 本次发布

- 单次、每天与每周计划，支持编辑、删除和启停。
- 关机前 5 分钟提醒，取消本次或延后 10 / 30 / 60 分钟。
- 独立闹钟与安全演示入口；清晰展示实际下次执行时间。
- 托盘运行、本地备份与记录；退出软件即停止所有计划。
- 作者与 GitHub 入口、音效开关、提醒音量及减少动态效果。

## 下载

| 文件 | 用途 |
| --- | --- |
| `StarSleep-Setup-1.0.0.exe` | Windows 10/11 x64 安装程序，包含桌面快捷方式 |
| `StarSleep-Source-1.0.0.zip` | 完整项目源码与开发说明 |
| `SHA256SUMS.txt` | 安装包与源码压缩包的校验值 |

第一次使用，建议先点「演示提醒」。**正式计划到点会强制关机，未保存内容可能丢失。**
点击窗口 × 会继续在托盘运行；从托盘退出后，所有计时停止。
星眠不判断 Agent 是否完成，也不能保证关闭本机后云端工作或计费停止。

当前安装程序未使用代码签名证书。测试以模拟时钟与安全关机替代器执行，
未实际关闭开发电脑。完整验证记录见仓库内的 `VALIDATION.md`。

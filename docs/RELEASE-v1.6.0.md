# 星眠 v1.6.0 · Agent 工具箱

第一作者 AsterVey。本轮为本地体验版，未发布 GitHub。原有计划、联动、美化及全部历史交付目录保留。

## 使用入口

点击主界面底部 **Agent 工具箱**，在「用量看板」「开源资源」「本机 Skills」之间切换。

安装请双击 **StarSleep-Setup-1.6.0.exe**。同目录的 **体验新版.cmd** 使用独立 preview-data，拦截真实关机，不覆盖当前安装；主动运行安装程序会升级现有安装。**StarSleep-Source-1.6.0.zip 是开发源码，不是安装包。**

## 用量看板

- 直接复用开源 **ccusage 20.0.24** 原版 Windows x64 引擎，随安装包附带，无需用户另装 Node 或 CLI。
- 读取 Codex 与 Claude Code 本地日志，查看今天、近 7 天、近 30 天的 Token 汇总、每日柱状图和模型分布。按本机时区归日。
- 区分未缓存输入、输出、缓存读取与缓存写入；推理已包含在输出中，不再次叠加。ccusage 负责原始日志解析与去重，星眠只适配其 JSON 报告和界面。
- 只读日志，不上传对话。看板可见时每 5 分钟刷新，隐藏、最小化、迷你模式或切换到其他页后停止新的定期请求；已启动的读取最多运行 60 秒。退出星眠会终止未完成的引擎进程。
- 「数据来源 → 目录与配置」可通过原生目录选择器设置数据根目录或恢复默认。Codex 目录应包含 sessions 或 archived_sessions；Claude Code 应包含 projects。
- 安全体验默认使用隔离日志目录，未选择真实目录时显示未找到日志。用户可主动选择真实目录做只读统计；选择结果保存在体验目录。
- 导出当前筛选的 JSON 摘要，仅含日期、模型、Token 汇总与来源状态，不附带原对话、本机路径或密钥。

**统计范围限制：** 这不是账号剩余额度、云端总用量或订阅账单。日志缺失、其他机器和未记录的使用量不会计入。Claude 普通桌面 Chat / Cowork 与 DeepSeek Harness 用量尚未接入；不会把它们显示为零。若一个来源读取失败，其他来源仍可显示，来源区明确说明缺口。

## 开源资源中心

内置 10 个经作者仓库核对的入口：ccusage、OpenAI Skills、Anthropic Skills、Claude 官方插件目录、Superpowers、antfu/skills、Vercel skills、MCP 参考服务器、Playwright MCP 与 DeepSeek Harness。

每项说明用途、适用客户端、使用方式、原作者、许可及核对日期。可按类别 / 客户端筛选、搜索用途或个人备注、收藏、填写 300 字个人备注、复制链接与说明，并打开作者仓库。

目录随版本提供，核对日期为 **2026-09-22**，不是实时排行，也不以 stars 数伪装质量评分。收藏不等于安装；点击链接不会自动执行安装命令。客户端兼容性、依赖及具体许可请以作者当前说明为准。

## 本机 Skills 清单

扫描当前用户 `.codex/skills`、`.agents/skills`、`.claude/skills`，显示名称、可提取的简介、所在客户端并支持搜索、打开文件所在目录。不会执行 SKILL.md 或其中脚本。

本次最多扫描 1500 个目录，界面一次显示前 200 个匹配项。仅提取常见单行 frontmatter 名称与简介，复杂多行简介回退到打开文件查看。不跟随符号链接，不扫描插件缓存、项目级技能、DeepSeek Profile。文件存在不代表客户端已经加载或启用。

## 数据与授权

收藏、个人备注和选定日志目录保存在独立版本 1 `toolbox.json`，原子替换并保留 `.bak`；损坏后尝试只读备份，保留原文件并停止相关保存，不影响原有计划调度。不会更改计划存储格式。

星眠原创部分继续使用现有禁止售卖许可；ccusage 保留原作者 MIT 许可，不受星眠重新许可。详情见 [开源复用记录](OPEN-SOURCE-v1.6.0.md)。

只有星眠运行期间，原有自动关机与提醒才有效；关闭窗口隐藏到托盘，完全退出停止，无开机启动、系统定时任务或后台服务。

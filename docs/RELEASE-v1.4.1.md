# v1.4.1 · Codex hooks 接入修复

v1.4.0 的安全体验入口将 hooks 写入体验数据中的 `test-clients/codex/hooks.json`，真实 Codex 无法发现该路径，但按钮和成功提示没有说明这是模拟配置。

v1.4.1 把真实接入放在主要入口，显示真实配置文件位置。安全模式下显式接入真实 Codex 或 Claude Code 本地会话时，仍由安全执行器拦截关机。模拟配置收进独立入口；客户端美化继续使用原有安全隔离规则。

## 使用

1. 双击交付目录的 `体验新版.cmd`，进入“Agent 与美化 → 夜间联动”。
2. 选择“接入真实 Codex（不关机）”，核对文件路径后配置。若已配置，按钮显示“移除真实接入”，不用再次操作。
3. 打开 Codex“设置 → Hooks”，查看用户级配置中的九个星眠事件，审核并信任。若设置页面原来已打开，离开后重新打开；仍未刷新时，等待现有任务结束再重启 Codex。
4. 保持星眠运行，给 Codex 发送新任务。右侧出现任务后才说明星眠收到事件；按需选择任务并开启夜间联动。

新 hooks 需要信任后才能执行，详见 [Codex 官方 hooks 说明](https://learn.chatgpt.com/docs/hooks)。本版本不替用户写入信任、不自动开启关机联动。安全体验即使完成倒计时，也不会关闭电脑。

正常安装请双击 `StarSleep-Setup-1.4.1.exe`；主动安装可能升级现有星眠。`StarSleep-Source-1.4.1.zip` 用于开发，不是安装包。暂未发布 GitHub。

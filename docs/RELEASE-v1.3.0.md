# 星眠 v1.3.0 · 轻量悬浮与星舰互动

第一作者：**[AsterVey](https://github.com/AsterVey)**。本版为本地体验版，尚未发布到 GitHub。

今晚的安排可以留在桌面一角，也可以提前看一周。

- **迷你模式**：复用原窗口，约 320×168 DIP。优先显示下一次关机，没有关机时显示下一次闹钟；支持置顶、暂停、隐藏和返回。保留搜索、筛选与排序，清空批量选择。提醒自动展开完整界面。
- **未来七天**：查看今天至未来六天的原定安排，按天浏览，每页 50 条；临时延后与跳过会同步反映。点击条目编辑原计划。
- **个人常用模板**：在计划编辑器或快捷计时中保存。可以改名、修改、删除；套用只填入内容，确认后才创建计划。单次模板自动选择下次该时刻，快捷模板从确认时开始倒计时。
- **星舰互动**：仪表表达待机、运行、暂停、关机提醒、闹钟和故障。点击电源形状的“发送星舰信号”按钮，可收到一次光波与电子反馈；它不会改变计划。支持键盘、短暂冷却和减少动态效果。

## 如何体验

先双击交付目录中的 **`体验新版.cmd`**：使用独立 `preview-data`，拦截实际关机，不覆盖当前安装及真实计划。安全测试标识会一直显示。请保留同目录的 `win-unpacked` 文件夹。

需要正式安装时使用 **`StarSleep-Setup-1.3.0.exe`**。主动安装将升级现有安装；本轮交付没有自动执行安装。

**`StarSleep-Source-1.3.0.zip` 是开发源码，不是安装包压缩版。** 普通使用无需下载源码、Node.js 或开发工具。

## 运行规则

仅软件运行时有效。关窗隐藏到托盘，任务继续；托盘明确退出后立即停止。没有系统任务计划、自动启动、后台服务或睡眠唤醒，不补执行错过的关机。到点强制关机可能丢失未保存内容。

七天预览按当前规则计算，不能保证软件退出后仍会执行。全局暂停和存储故障保护有不同标识。

## 数据与许可

计划继续使用版本 2 的 `schedules.json`，导入导出格式不变。个人模板、窗口位置、置顶和互动偏好单独存放于版本 1 的 `experience.json`，原子写入并保留备份。体验文件无法恢复时保留原文件并停用相关保存功能，既有计划继续运行。

保留 AsterVey 第一作者署名和现有禁止售卖许可；可用于个人及商业工作，不得售卖本软件或改版。历史 GitHub 版本与本地 v1.2.0 产物保持原样。

# 星眠 v1.7.0 · Skills 发现与安装

第一作者：AsterVey · 本地体验版，尚未发布 GitHub。

## 开始使用

安装请运行 **StarSleep-Setup-1.7.0.exe**。保留现有安装体验新版，请运行同目录 **体验新版.cmd**；安全体验使用独立数据，关机被替代，技能安装也只写入隔离目录。源码 ZIP 用于开发，不是安装程序。

打开底部 **Agent 工具箱 → 发现与安装**：

1. 输入用途关键词（例如 `testing agent skills`），或 `owner/repo` / GitHub 仓库首页链接。支持相关度、最近更新和 Stars 排序，也提供设计、审查、测试、文档场景入口。
2. 点击“发现 Skills”，筛选仓库内的技能，再点“查看并审查”。此时不会安装。
3. 查看原文、脚本与敏感操作线索，核对来源、用途、依赖、许可证和目标目录。勾选确认后，一次点击安装已审查的版本。
4. 到目标客户端新对话中确认发现技能，必要时重启客户端。星眠的“已安装”代表文件已写入，不代表客户端已经加载或外部依赖已就绪。

## 客户端配置

| 目标 | 默认写入位置 | 使用边界 |
| --- | --- | --- |
| Codex / 共享目录 | `~/.agents/skills/<name>` | 支持共享目录的其他 Agent 也可能发现该技能 |
| Claude Code | `CLAUDE_CONFIG_DIR/skills/<name>` 或 `~/.claude/skills/<name>` | 不等于普通 Claude 桌面聊天 |
| DeepSeek Harness | `DSH_HOME/skills/<name>` 或 `~/.dsh/skills/<name>` | 须与 Harness 实际启动使用的数据目录一致 |
| Claude 桌面 Chat / Cowork | 导出技能 ZIP，在 Claude 自定义 / Skills 上传 | 星眠不操作 Claude 云端账号；导出后仍须用户上传 |

正式运行时，“更改目标目录”使用 Windows 原生目录选择器；选择客户端实际使用的 **Skills 文件夹**。安全体验固定使用隔离目录。目标已有安装/备份记录时不允许切换目录，以免丢失管理关系。

安装不执行任何脚本，不修改权限、不代填密钥、不安装额外 Python/npm 依赖，也不会把插件或 MCP 仓库冒充 Skills 安装。同名技能不会覆盖。包含二进制/压缩文件、符号链接、子模块、超限内容或无效元数据的技能停止自动安装。

## 新增的日常管理

- 安装记录保存仓库、提交版本、目标、时间和目录。
- 移除前核对所有文件；有修改、新增或删除时停止，保留用户内容。
- 移除将目录移动到客户端 Skills 目录外的 `.starsleep-disabled/<id>`，可以恢复原版本；恢复也不覆盖同名目录。
- 本机 Skills 清单包含自定义安装目标，安装后可刷新查看。
- 安装记录与目标目录偏好独立保存，不改变原有计划存储。

## 搜索和审查的实际范围

实时搜索使用 GitHub 官方 REST API，仅公开仓库，不读取登录凭据。每页 12 个结果，最多查看前 120 个，相同查询缓存 5 分钟。GitHub 限流、离线或超时会明确报错。旧有资源收藏离线可用。

仓库发现固定到提交 SHA，下载时核对 Git blob 标识。审查和安装使用同一份内存快照，30 分钟过期；保留最近 3 份审查。每个技能最多 150 个文件、单文件 1 MB、合计 8 MB；保留最近上级目录的常见许可证/NOTICE 文件。

审查为星眠的**静态规则检查**：标出脚本、联网链接、凭据、动态执行、破坏性命令、指令覆盖及目录外依赖等线索，显示文件与行号，可查看所有文件原文。可能误报/漏报；不包含沙箱运行、完整语义分析或 Cisco Skill Scanner。没有命中规则不代表安全认证。搜索相关度、Stars 和更新日期只辅助选择，不代表“最有用”评级。

原作者技能保持原许可证。星眠自身继续采用禁止售卖的软件许可；该限制不替代第三方许可。

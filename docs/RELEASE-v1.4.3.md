# 星眠 v1.4.3 · 三端美化配置

第一作者 AsterVey；继续沿用禁止售卖许可。本版本仅供本地体验，未发布 GitHub，保留全部历史版本。

## 使用

安装请运行 **StarSleep-Setup-1.4.3.exe**。想保留当前安装与真实数据，请运行同目录 **体验新版.cmd**：独立数据、安全关机替代器，三端美化也只写入隔离测试文件。**源码 ZIP 是开发源码，不是安装包。**

入口「Agent 与美化 → 原界面美化」。导入后按客户端筛选，查看对应检测结果，再配置。下载的 PNG / JPEG / WebP 会自动归入 DeepSeek 背景页。配置真实客户端需正常启动安装版，安全体验不会改变真实外观。

## 这次新增

- 一个文件入口接收 JSON、TXT、CSS、Dream Skin ZIP 和背景图片，识别格式后归入对应库。
- Codex 原生主题兼容直接 JSON；Claude codeBg 支持半透明配色；旧有导入格式继续保留。
- DeepSeek Dream Skin 主题包、数据目录选择和插件检测、主题 / 背景应用，以及外观恢复。写入前显示路径并要求退出 DeepSeek，重开后核对。
- DeepSeek 恢复保留其他设置；外部外观更改、损坏状态、同标识不同主题都拒绝覆盖。
- 三端配置指南、按客户端筛选和明确的加载器条件。CSS 仅收藏 / 复制 / 导出，ZIP 由对应引擎处理，星眠不会执行未知脚本或自动修改客户端二进制。

详细操作与支持格式见源码中的 docs/CLIENT-THEMES.md。

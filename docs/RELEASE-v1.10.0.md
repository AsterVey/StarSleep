# 星枢 StarNexus v1.10.0 · 日常工作台

第一作者：AsterVey。Windows x64 发布版，源码及安装包发布于 AsterVey/StarSleep。

## 快捷入口

按 **Ctrl+K**，或点击顶部搜索图标，输入“用量”“主题”“设置”“记录”等关键词。方向键选择，Enter 打开，Esc 返回。功能名称优先匹配；没有结果时可以直接修改关键词。

新建计划、快捷计时和临时暂停仍打开原有确认面板，不会因搜索或选择而立即关机。编辑器或提醒打开时不会用快捷面板覆盖它；提醒出现时快捷面板自动让位。

## Agent 用量与工具

- 用量看板新增每日明细、日均已记录用量、缓存读取占输入比例、有记录天数。
- 明细按所选来源和日期范围汇总，展开后可以查看输入、输出、缓存和总量。输入占比的分母包含未缓存输入、缓存读取和缓存写入；它不是费用节省率。
- 手动刷新绕过已完成的短期缓存，并发请求共用一次扫描；Codex 与 Claude Code 统计并行进行。
- 部分来源未找到或读取失败时，明确说明汇总范围；缺失记录不当作已知的零使用量。
- 工具页切换保留用量筛选、资源搜索、资源备注草稿及 Skills 搜索状态。关闭软件前仍需保存资源备注。
- 非当前用量页不继续启动定时扫描，正在进行的只读扫描可以完成；完全退出会停止统计子进程。

继续复用随安装包提供的 ccusage 20.0.24（MIT）。没有增加网络统计服务或新依赖。Claude Chat / Cowork 与 DeepSeek Harness 的 Token 格式仍未接入；此页不是账号剩余额度或订阅账单。

## 系统维护与界面

- 系统维护新增运行摘要：计划调度、Agent 联动、界面状态和最近执行记录。
- 体检汇总就绪与待核对数量，可选择“只看待处理项”。导出仍包含完整脱敏体检结果。
- 修复重试成功后残留旧错误的问题；扫描和导出期间避免重复操作。
- 减少 Agent 页重复标题占用的空间，改善普通说明与错误反馈的层级；保留冷蓝星际场景和星门开场。
- 保持键盘焦点恢复、小窗口滚动及 125% / 150% / 200% 缩放操作。

## 下载文件与使用

**先体验：双击 `体验星枢.cmd`。** 使用独立数据和安全关机替代器，不覆盖现有安装和真实客户端配置。

**安装：双击 `StarNexus-Setup-1.10.0.exe`。** 正常启动具备真实关机能力，仅软件运行时有效。关窗口隐藏到托盘，从托盘退出停止任务。

`StarNexus-Source-1.10.0.zip` 是完整开发源码，不是安装包。截图位于 `screenshots`，测试报告及可复核输出随交付提供。

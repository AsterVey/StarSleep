## 同机测量

每个版本分别测试 0 / 1 / 50 / 500 条计划。前台约 3.5 秒采样，隐藏约 2.2 秒采样。CPU 是 Electron 所有相关进程 CPU 百分比相加，内存是其工作集相加；共享内存可能重复计算。这是短时观测，不是跨设备保证。

新版初测 38–47 FPS，发现等待间隔叠加渲染耗时，修正为基于时间点的帧间隔后达到 53–58 FPS（目标 60）。15 秒闲置后的实测约 24 FPS。新版前台 CPU 高于经典版，3D 效果有实际成本；设置中可切换经典、低负载或静态模式。

两个版本的闲置完整计划状态发送及同步写盘均为 **0**；新版隐藏、最小化、迷你模式的场景绘制增量为 **0**，迷你模式保持同一渲染进程和单窗口。没有新增调度器或音频控制器。提醒期间背景绘制停止，WebGL 上下文丢失仍可正常新建计划。

使用延迟帧回调的确定性负载验证从标准逐级到静态，再手动恢复；该测试是人工施加低帧率，不冒称某款低端显卡的自然表现。GPU 进程 CPU/内存已记录在原始 JSON，硬件 GPU 利用率、显存与耗电量未测量。

## 真实来源与隔离效果

五个可下载资源均从固定提交的原作者仓库真实获取，校验摘要与解析成功；包括 Codex Warm 两种模式、Claude Arizona / Moonside 和 DSH Aurora Test。社区入口不自动下载可执行插件。

Codex、Claude、DeepSeek 的配置确认、写入、备份、恢复只在隔离目录执行。**不代表用户已安装的真实客户端已换肤**；本轮没有修改真实客户端外观、完整性标记或 hooks。软件中的“效果已确认”由用户明确操作产生，不由写文件成功自动产生。
